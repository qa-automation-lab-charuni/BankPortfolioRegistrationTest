QA Automation Portfolio - Bank Registration Testing

Welcome to my QA Automation Portfolio!

This repository contains my hands-on automation testing project, 
demonstrating my practical knowledge of web application testing using different automation frameworks and technologies.

**PROJECTS**

1. Bank Registration Automation – Java
Folder: "Bank-Registration-Tests"

An automated testing project focused on validating the bank application registration process.

Technologies & Tools:
- Java
- Selenium WebDriver
- TestNG
- Maven
- Cucumber / Gherkin
- IntelliJ IDEA

Testing Focus:
- Navigating through the bank application
- Automating the user registration process
- Identifying and interacting with web elements
- Validating registration workflows
- Verifying successful registration and user profile information

2. Playwright Automation Testing – TypeScript
Folder: "playwright-ts-tests"

A web automation testing project developed using Playwright and TypeScript 
to explore modern browser automation and end-to-end testing practices.

Technologies & Tools:
- Playwright
- TypeScript
- Node.js
- Visual Studio Code

Testing Focus:
- Browser automation
- End-to-end testing
- Web element interaction
- Test execution and validation
- Exploring modern automation testing practices
